```mermaid
flowchart TD
    title 百川平台任务广场和PMP平台之间的数据流 - 流程图
    
    Start([开始]) --> A[用户在百川广场领取任务<br/>硬件试题结构化]
    A --> B[用户编辑题目并提交]
    
    B --> C{是否通过任务工单管理分配?}
    C -- 是 --> D[任务进入PMP平台<br/>「任务工单管理v25」<br/>状态=待领取]
    D --> E[搜索状态=待领取的任务]
    E --> F[通过【指派】按钮分配任务<br/>指定用户uid]
    F --> G[分配指定用户后]
    G --> H[任务进入「任务审核」<br/>硬件试题结构化审核<br/>一审]
    
    C -- 否 --> H
    
    H --> I{一审审核是否通过?}
    I -- 是 --> J[进入内审]
    J --> K[内审<br/>题库-内审质检-通用内审]
    K --> L{内审审核是否通过?}
    L -- 是 --> M[内审审核通过]
    L -- 否 --> N[内审审核驳回]
    
    I -- 否 --> O[重新回到广场任务<br/>硬件试题结构化 任务中]
    O --> A
    A --> B
    B --> H
    H --> I
    
    I -- 是 --> J
    J --> K
    K --> L
    
    M --> End([结束])
    N --> End
```
