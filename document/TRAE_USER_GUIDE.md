# Trae 功能介绍与使用指南

***

## 📖 引言

### 什么是 Trae？

Trae 是一款强大的 AI 辅助工具，它能帮助我们更高效地完成各种任务。无论是写代码、处理文档、数据分析还是日常办公，Trae 都能成为你的智能助手。

### 为什么要学习 Trae？

- **提升效率**：AI 可以自动完成重复性工作，让你专注于更有价值的任务
- **降低门槛**：即使你不是技术专家，也能借助 Trae 完成专业工作
- **团队协作**：统一的工具平台让团队协作更加顺畅

### 这份指南适合谁？

**所有人！** 无论你是技术专家还是刚接触电脑的新手，这份指南都会用最简单的语言帮助你理解和使用 Trae。

***

## 🔄 Trae 四种使用模式

Trae 提供了四种不同的使用方式，就像一辆汽车可以在城市道路、高速公路、乡间小路等不同场景行驶一样，你可以根据自己的需求选择最合适的模式。

### 四种模式对比表

| 模式名称               | 简单理解      | 适用场景             | 主要特点            |
| ------------------ | --------- | ---------------- | --------------- |
| **⭐️IDE 集成模式**     | 在编程软件里使用  | 编写代码、开发项目        | 与代码深度集成，适合程序员   |
| **⭐️Trae SOLO 模式** | 独立的应用程序   | 日常办公、文档处理、随时随地使用 | 功能完整，界面友好，适合所有人 |
| **插件模式**           | 作为其他软件的插件 | 在熟悉的软件中添加 AI 能力  | 无缝融入现有工作流程      |
| **CLI 模式**         | 在命令行中使用   | 高级用户、自动化脚本       | 适合技术人员做批量处理     |

## 🎯 重点功能详解

### A. IDE 集成模式与 Trae SOLO 模式概览

这是 Trae 最核心的两种使用方式：

**IDE 集成模式** 像是把 AI 助手直接放进你的代码编辑器里，当你写代码时，它就在旁边随时待命。

**Trae SOLO 模式** 像是一个独立的智能办公助手，你可以用它来写文档、做分析、聊天等各种事情。

### B. IDE 集成模式功能模块

#### B-1. MCP（多智能体协作平台）

**简单来说**：MCP 就是让多个 AI 助手一起协作完成任务。

**使用场景**：当你有一个复杂任务时，可以让一个 AI 负责调研，另一个 AI 负责写代码，再让一个 AI 负责测试，它们会自动配合完成工作。可以把MCP封装成不同的agent


#### B-2. Skill（技能）的安装与应用

**简单来说**：Skill 就是 Trae 的"插件"，可以为 Trae 添加各种特殊能力。

**使用场景**：如果你需要处理 Excel 数据，可以安装"数据分析"技能；如果你需要画图，可以安装"图表可视化"技能。

**如何安装技能**：
- 可以手动安装项目和全局技能，安装的项目技能可以引用到全局中
- 可以让AI 自动安装技能，根据任务需求自动安装相关的技能
- 技能市场下载导入技能
- 技能市场：[skill.sh](https://www.skills.sh/) 、[skillhub](https://skillhub.cn/)


#### B-3. 模型选择与配置

**简单来说**：不同的 AI 模型就像不同的专家，有的擅长写作，有的擅长编程，有的擅长分析。

**如何选择模型**：

| 模型类型 | 适合场景       | 特点            |
| ---- | ---------- | ------------- |
| 通用模型 | 日常对话、普通任务  | 综合能力强，适合大多数场景 |
| 代码模型 | 编写和调试代码    | 对编程语言有深入理解    |
| 创意模型 | 写作、设计、创意内容 | 想象力丰富，适合创作    |
| 分析模型 | 数据分析、逻辑推理  | 严谨准确，适合复杂分析   |



#### B-4. 插件系统的扩展功能

**简单来说**：插件可以让 Trae 连接到其他软件和服务。

根据需要安装不同的插件，如文档插件、代码仓库插件、办公软件插件、通讯工具插件等。


### C. Trae SOLO 模式

Trae SOLO 是一个独立的应用程序，你可以在电脑和手机上使用。

#### C-1. 桌面端下载安装

**Windows / Mac 安装步骤**：

```
1. 打开浏览器，访问 Trae 官方网站
       ↓
2. 找到"下载"页面
       ↓
3. 选择对应系统的安装包（Windows 选 .exe，Mac 选 .dmg）
       ↓
4. 下载完成后，双击安装包
       ↓
5. 按照安装向导完成安装
       ↓
6. 启动 Trae SOLO 应用
```

#### C-2. 手机端下载安装

**iOS / Android 安装步骤**：

```
1. 打开手机应用商店（App Store 或应用市场）
       ↓
2. 搜索"Trae SOLO"
       ↓
3. 点击"下载"或"安装"
       ↓
4. 等待安装完成
       ↓
5. 打开应用，完成注册或登录
```

#### C-4. 核心功能使用方法

**1. 基础对话**

```
在输入框中输入你的问题或需求，然后点击发送。
例如："帮我写一封邮件"、"解释什么是人工智能"
```

**2. 使用技能**

```
点击底部的[技能]按钮，选择需要的技能，然后按照提示操作。
```

**3. 上传文件**

```
点击[文件]按钮，选择电脑或手机上的文件，Trae 可以帮你分析、处理或转换文件内容。
```

**4. 语音输入**

```
点击[语音]按钮，说出你的需求，Trae 会自动识别并转换为文字。
```

#### C-5. 数据同步机制

Trae SOLO 支持多设备数据同步，你的聊天记录和设置会自动同步到云端。

```
数据同步流程：
┌─────────────┐      ┌─────────────┐      ┌─────────────┐
│   电脑端     │      │    云端      │      │   手机端     │
└──────┬──────┘      └──────┬──────┘      └──────┬──────┘
       │                    │                    │
       │   自动上传同步      │                    │
       └───────────────────▶│                    │
                            │                    │
                            │   自动下载同步      │
                            └───────────────────▶│
                                                 │
                            ◀─────────────────────┘
                               手机端更新也会同步回云端
```

**注意**：确保所有设备都使用同一个账号登录，并且连接到网络，数据就会自动同步。

## 💡 使用案例展示区

### 案例 1：IDE 集成模式 - 代码调试

**场景描述**：程序员小张在写代码时遇到了一个错误，不知道如何修复。

**操作步骤**：

1. 在 IDE 中选中出错的代码
2. 打开 Trae AI 面板
3. 输入："帮我分析这段代码的错误"
4. Trae 会分析代码并给出修复建议

**预期效果**：Trae 会指出代码中的错误位置和原因，并提供修复后的代码。

***

### 案例 2：IDE 集成模式 - 代码解释

**场景描述**：小李刚加入团队，看到同事写的复杂代码不太理解。

**操作步骤**：

1. 在 IDE 中选中需要理解的代码段
2. 在 Trae 面板中输入："请解释这段代码的功能"
3. 等待 Trae 的回复

**预期效果**：Trae 会用通俗易懂的语言解释代码的功能、执行流程和关键逻辑。

***

### 案例 3：Trae SOLO 模式 - 文档总结

**场景描述**：小王收到一份很长的项目报告，需要快速了解内容。

**操作步骤**：

1. 打开 Trae SOLO 应用
2. 点击\[文件]按钮，上传项目报告
3. 输入："帮我总结这份报告的主要内容"
4. 等待 Trae 处理

**预期效果**：Trae 会提取报告的关键点，生成一份简洁的总结。

***

### 案例 4：Trae SOLO 模式 - 数据表格处理

**场景描述**：财务人员小陈需要对 Excel 表格中的数据进行分析。

**操作步骤**：

1. 打开 Trae SOLO 应用
2. 点击\[文件]按钮，上传 Excel 文件
3. 输入："帮我分析这份表格中的销售数据，找出销售额最高的产品"
4. 等待 Trae 分析

**预期效果**：Trae 会读取表格数据，进行分析，并给出结果和可视化图表。

***

### 案例 5：Trae SOLO 模式 - 创意写作

**场景描述**：市场部的小林需要写一篇产品推广文案。

**操作步骤**：

1. 打开 Trae SOLO 应用
2. 在输入框中输入："帮我写一篇关于智能手表的产品推广文案，突出健康监测功能"
3. 可以补充要求："风格要活泼，适合年轻人"
4. 点击发送

**预期效果**：Trae 会生成一篇符合要求的推广文案，可以直接使用或稍作修改。

## 📝 总结

Trae 是一个功能强大的 AI 助手，提供了多种使用方式来满足不同场景的需求：

- **IDE 集成模式**：适合程序员在开发过程中使用
- **Trae SOLO 模式**：适合日常办公和随时随地使用
- **插件模式**：让你在熟悉的软件中也能使用 AI 能力
- **CLI 模式**：适合高级用户进行自动化操作

无论你是技术专家还是普通用户，都可以根据自己的需求选择合适的方式来使用 Trae，提升工作效率。
